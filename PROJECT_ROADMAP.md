# Canadian French Localization Assistant

## Overview

A secure Azure-hosted localization tool that translates English content into Canadian French while validating length constraints for websites, user interfaces, marketing campaigns, email content, and digital experiences.

---

# Architecture

```text
Azure Static Web App
        ↓
Azure Function
        ↓
Azure AI Translator
```

---

# Current Features

## Translation
- English → Canadian French translation
- Azure AI Translator integration
- Secure backend through Azure Functions
- Shareable web application
- Automatic GitHub deployments

## Character Management
- English character counter
- French character counter
- User-defined character limits
- PASS / FAIL validation
- Over-limit reporting

## Productivity
- Copy translation to clipboard
- Real-time character tracking
- Azure-hosted solution
- Team-accessible URL
